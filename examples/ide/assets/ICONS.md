# Explorer icon attribution

`file.png`, `directory-closed.png`, and `directory-open.png` are transparent
16 px PNG renderings of the corresponding 16 px
[GitHub Octicons](https://github.com/primer/octicons):

- `file-16`
- `file-directory-fill-16`
- `file-directory-open-fill-16`

The silhouettes use one flat `#8b95a7` color to suit the dark explorer. The
Octicons MIT license is included in `OCTICONS-LICENSE.txt`.
