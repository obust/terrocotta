# Vendored text samples

These files are frozen inputs for the text-heavy UI benchmark. Benchmark runs
must use these local files and must not fetch from the network.

| File | Source | License / notice |
|---|---|---|
| `gutenberg-alice.txt` | [Project Gutenberg eBook 11](https://www.gutenberg.org/ebooks/11) | Underlying work is public domain in the United States; retain the included Project Gutenberg notice. |
| `wikimedia-typography.json` | [Wikimedia API: Typography](https://en.wikipedia.org/wiki/Typography) | Wikipedia text is generally CC BY-SA 4.0; attribution and share-alike terms apply. |
| `rfc-5732.txt` | [RFC 5732](https://www.rfc-editor.org/rfc/rfc5732) | Retain the RFC copyright and rights statements included in the file. |
| `python-introduction.html` | [Python tutorial](https://docs.python.org/3/tutorial/introduction.html) | Python documentation is under the Python Software Foundation License. |

The download date and exact URLs are recorded in `metadata.json`.
