## Added

- Added `Normal` and `PreWrap` whitespace modes for text, with configurable tab widths.
- Added allocation-traced benchmarks for element-tree traversal and retained text layout, including reproducible corpora and checked baselines.

## Changed

- Represented views as structured trees with one stack-based depth-first walker, substantially reducing allocations while retaining operation-stream iteration and collection helpers.
- Reworked text preparation, wrapping, and caching to reuse width-independent measurements across rebuilds and resize passes. `Normal` remains the default whitespace mode.
- Removed the implicit scissor scope around each custom canvas to substantially reduce rendering overhead. Canvas callbacks must keep drawing within their supplied bounds; canvases still inherit clipping from overflow-clipped ancestors.

## Fixed

- Preserved spaces, tabs, explicit line breaks, and trailing whitespace when text uses `PreWrap`.
- Kept the newest text-measurement cache entries when the cache exceeds its size limit.
