## Added

- Added the Sunnyland playable platformer example, demonstrating real-time keyboard input, custom canvas rendering, floating UI overlays, capability-scoped texture and audio loading, deterministic frame capture, and a pure gameplay simulation with explicit events.

## Changed

- Upgraded roc-ray from 0.10.0 to 0.12.2.
- Pinned Roc nightly-2026-11-15-f25da45.
- Moved `Element.iter` and `Element.collect` onto `Element.View`. Use `view.iter()` and `view.collect()` methods.
- Migrated Screwbot to roc-ray's typed shader uniforms, using `Math.Vec2` for GLSL `vec2` values.

## Fixed

- Fixed Screwbot shader runtime validation by matching shader uniform names and types to the GLSL declarations.
